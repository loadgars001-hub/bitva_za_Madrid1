⚔️ # bitva_za_Madrid

This is a simple browser game made with HTML (currently in Russian, but an English version will be added in the future).

🎮 ## How to play

You play as Madrid (Spain) and must defend Madrid from the enemy — Paris (France).
France is divided into:
North
South
Regular territories

There is also Italy, which does not participate in any wars.

💰 ## Economy & resources

You earn coins by defeating enemies

There are stars (additional currency/resource)

The fortress has 100 HP

When an enemy reaches your fortress:

it gradually deals damage over time

🏗 ## Game phases

The game includes a rest phase, during which you can:

build a fortress
spawn units
prepare for the next wave

You can:

interrupt the rest phase
press the “Start War” button
immediately switch to battle

🪖 ## Units

There are 2 types of units:

⚔️ Warrior
🏹 Archer

🏰 Buildings

You can build a base in a designated area

Cost: 80 coins

🌍 ## Territories

On the left side, you can see the territories controlled by Spain (Madrid)

Each territory generates income: +0.8 gold/sec

⚔️ ## Controls

Clicking ⚔️ spawns a warrior

🌦 ## Additional features

At the top of the screen you can see:
current wave
war phase
rain phase
